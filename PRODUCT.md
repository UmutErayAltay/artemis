# Product

## Platform
Native Windows desktop, PySide6/Qt. Impeccable platform schema web/ios/android/adaptive does not represent this existing Windows stack; do not infer a web migration.

## Users
Current confirmed user: Umut, a software developer using Artemis on Windows. Broader audiences remain undecided.

## Product Purpose
A Turkish desktop voice assistant that accepts voice and text commands, runs computer/project tools, communicates state and asks for required approvals. A desktop pet provides a companion and quick entry surface.

## Operating Context
Windows desktop; Turkish/English mixed speech. Normal commands should not require repeated application-by-application setup; sensitive operations retain their existing approval rules. User also manages models, microphone, projects and generated pets.

## Capabilities and Constraints
Existing Python/PySide6 application. Preserve voice, tool execution, safety checks, installed pets and their 1/2/3-click behavior. Existing functional code is not a reason to preserve its old visual design. User requests a complete visual identity replacement and four selectable themes: light, dark, light-dominant and dark-dominant. Exact mixed-theme palette and default theme remain open.

## Brand Commitments
Name: Artemis. Turkish user-facing copy. User selected full visual identity replacement on 2026-10-27. On 2026-10-27 the user approved a restrained workspace with warm Artemis companion language. Show the selected pet next to the top-left Artemis brand. The wake name is user-configurable and independent from the unchanged Artemis app name.

notes outside the app: ../notes/artemis-arayuz-incelemesi-20261027.md. Current synthetic screenshots: reports/ui-review-20261027/. Source: artemis/channels/desktop/. No invented customer testimonials or usage benchmarks.

## Product Principles
- Commands and current state stay understandable.
- Preserve user data and existing security behavior through the redesign.
- Keep technical configuration available without overwhelming daily tasks.
- The same theme applies consistently to the application surfaces.
