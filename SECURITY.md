# Güvenlik politikası

## Desteklenen sürüm

Yalnız en güncel sürüm desteklenir ([Releases](https://github.com/UmutErayAltay/artemis/releases)).

## Açık bildirme

Güvenlik açığını herkese açık issue olarak açmayın. GitHub'da bu deponun **Security** sekmesinden
**Report a vulnerability** (özel Security Advisory) ile bildirin. Kurucu henüz imzasızdır
(SignPath başvurusu beklemede); sürümleri `SHA256SUMS.txt` ile doğrulayın.
